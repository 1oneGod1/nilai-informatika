# Grade 11 AI Studio

Fourteen 80-minute continuation meetings after BSD Webcam Live Classifier, as reported by the teacher. English defaults with an Indonesian switch. Earlier activities remain optional references; no BSD completion or assessment records are imported.

Students enter through their existing name/password grade page. The same 12-hour session convention as the other studios is used. Teacher UI requires the teacher-preview session and matching verified Firebase teacher identity. Local synthetic preview is restricted to localhost/127.0.0.1. Classroom notes and companion quiz scores are browser-local, keyed by student ID, and never written as official grades.

Formative activities: meeting 1, dataset revision and fixed held-out tests; meeting 4, KNN K=1/3/5 comparison; meeting 13, navigation modification tested for finish, dead end, and retry. Meeting 14 provides an individual demonstration. These are teaching recommendations; existing assessment definitions, weights, and database rules remain authoritative.

The complete BSD course overview allocates 25 hours. This continuation provides 18 hours 40 minutes.
